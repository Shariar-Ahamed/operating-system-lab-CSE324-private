# Operating System Lab (CSE324)

This is a private repository created for the **Operating System Lab (CSE324)** course at **Daffodil International University**.

## 📌 Purpose
This repository is used to store:
- Lab class practice codes
- Shell script problems
- Scheduling algorithm implementations
- Loop, condition, and logic-based practice tasks
- Notes and experiment files related to Operating Systems

All codes and materials are organized gradually according to lab classes for better understanding and revision.

---

## 🛠 Technologies & Tools
- Bash / Shell Script
- Linux Commands
- Scheduling Algorithms (FCFS, SJF)
- Online Bash Compiler
- Visual Studio Code
